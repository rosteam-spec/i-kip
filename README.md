# i-kip — современные измерительные приборы

Сайт на русском языке: новости о новинках мировых производителей измерительных
приборов и аналитические обзоры со сравнительными таблицами.

Направления: радиоизмерения, электроизмерения, экология и мониторинг, метрология.

## Технологии

- **Next.js 16** (App Router) + **React 19**
- **TypeScript**
- **Tailwind CSS 4** + shadcn/ui
- Контент — статические данные в TypeScript (без базы данных)

## Локальный запуск

Требуется **Node.js 20.9 или новее**: https://nodejs.org

```bash
npm install     # установить зависимости (один раз)
npm run dev     # запустить сайт в режиме разработки
```

Откройте в браузере: http://localhost:3000

## Где редактировать контент

| Что | Файл |
|---|---|
| Новости | `src/data/news.ts` |
| Обзоры и сравнительные таблицы | `src/data/reviews.ts` |
| Типы данных (структура материала) | `src/data/types.ts` |
| Название сайта, счётчики в подвале | `src/data/index.ts` |

После изменения файлов в `src/data/` страница обновится автоматически
(в режиме `npm run dev`), ничего пересобирать не нужно.

## Структура проекта

```
src/
├── app/            # страницы Next.js (App Router)
├── components/
│   ├── ikip/       # компоненты сайта: шапка, hero, карточки, статьи, поиск…
│   └── ui/         # библиотека готовых компонентов (shadcn/ui)
├── data/           # ВЕСЬ КОНТЕНТ САЙТА — новости и обзоры
├── hooks/          # вспомогательные React-хуки
└── lib/            # утилиты
public/             # логотип, robots.txt
```

## Публикация в интернете (Vercel)

1. Загрузите код на GitHub.
2. Зайдите на https://vercel.com → **Add New → Project** → выберите репозиторий.
3. Нажмите **Deploy** — настройки определятся автоматически.
4. Подключите свой домен: **Project → Settings → Domains**.

Подробная пошаговая инструкция — в PDF «План запуска сайта после регистрации домена».
